# FWECSA register map

Generated by `tools/gen_docs.py` from `registers.py`; do not edit by hand.

Source: Daikin *FWECSA Installation and operation manual*, FC66003946 Rev 00, NETWORKS AND CONNECTIVITY. The manual numbers each table from 1; the Modbus address is that number minus one. Scales and the meaning of the two-way flags are not in the manual: see the docstring of `registers.py` for what was measured and what is assumed.

Entity ids assume the default prefix `fancoil`. The climate entity `climate.fancoil` is built from several of these.
